# Saleem Pandugalla — Portfolio Starter

A responsive, premium-dark portfolio starter made with plain HTML, CSS and JavaScript. No build step or package installation is required.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use a local preview extension.
3. Edit `index.html` to update your information and `styles.css` to customize the design.

## Before publishing — important checklist
- Replace `YOUR_EMAIL@example.com` with your professional email address.
- Replace the generic LinkedIn URL with your real profile URL.
- Add a PDF resume and a working resume-download button if desired.
- Confirm dates, internship descriptions, certification names and project features are accurate.
- Add screenshots and live demo links for projects you can demonstrate.
- Remove any skills or claims you cannot explain in an interview.
- Test all links and the layout on a phone.

## Publish
You can publish this static site with GitHub Pages, Netlify or Vercel. Upload/push the folder to a GitHub repository and follow the host's static-site deployment steps. A custom domain is optional.

## Tech
- HTML
- CSS (responsive layout, gradients, reduced-motion support)
